# No Demonstrator data in this repository

This repository is public, so it must never contain data from a SPHEERE Demonstrator, such as the Forua IFC model, partner energy inputs or measurements. That includes test fixtures, sample files, screenshots and issue attachments. Every IFC model in the repository is synthetic, generated by a committed IfcOpenShell builder. Generated models also have exact, known geometry and thermal properties, so simulation results can be checked by hand. Data pushed to a public repository cannot really be recalled, so this rule is cheaper to keep than to break.

## Considered Options

- **Use the Forua IFC and make the repository private.** Rejected, because the repository is meant to be shared as a teaching example.
- **Use an openly licensed sample model, such as buildingSMART's Duplex Apartment.** It is realistic, but its thermal properties are incomplete and unknown, so the expected simulation output cannot be stated exactly.
